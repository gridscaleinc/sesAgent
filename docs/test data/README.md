# Secure Talent Match AI test data

Generated files for functional testing.

- `requirements_txt`: 12 JD / project requirement text files.
- `requirements_json`: 12 structured project requirement JSON files.
- `resumes_docx`: 12 Word resume files.
- `resumes_xlsx`: 12 Excel resume files. Each file is one candidate resume.
- `resumes_txt`: 12 plain text resume files.
- `resumes_json`: 12 structured resume JSON files.
- `ats_csv`: 12 ATS CSV files. Each CSV contains multiple candidate rows and is intended to test multi-candidate CSV import.

Legacy `.doc` and `.xls` are intentionally not generated because the product asks users to convert them to `.docx` and `.xlsx`.
