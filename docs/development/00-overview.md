# Secure Talent Match AI MVP Overview

## 1. 产品定位

Secure Talent Match AI 是面向日本 HR Tech、IT 派遣、SES、人材紹介和 RPO 场景的本地优先 AI 採用匹配增强模块。

产品不替代客户现有 ATS，而是在 ATS、Excel、简历文件夹和历史人才库旁边增加一层 AI 辅助能力，帮助 HR 和项目负责人围绕具体项目需求快速完成候选人初筛、人才库 rediscovery、面试准备和结果导出。

一句话定位：

> 连接既有 ATS / Excel / 简历库，用本地优先 AI 帮 HR 从投递简历和历史人才库中快速找出适合项目需求的人才。

## 2. 核心价值

- 从项目需求或 JD 中自动拆解硬性条件、加分条件、风险项和面试验证点。
- 将 PDF、Word、CSV 和本地简历文件夹结构化为可检索的人才库。
- 输出候选人排序、总分、分项分、推荐理由、风险点和证据来源。
- 为每名候选人生成技术验证题、项目复盘题、风险追问和面试评分表。
- 默认本地处理候选人数据；可选 API 模式必须先经过脱敏层。

## 3. 目标客户

MVP 第一阶段优先服务项目制、简历量大、数据敏感且已有招聘系统的客户。

| 客户类型 | 典型痛点 | MVP 切入理由 |
| --- | --- | --- |
| IT 派遣 / SES / 外包公司 | 项目需求变化快，需要从工程师库中快速找出可动人才 | 项目制匹配强，价值容易量化 |
| 中大型企业 HR | 已有 ATS，但 AI 深度不足，候选人数据出境敏感 | 适合私有化增强模块 |
| 人材紹介 / RPO | 历史候选人库庞大，检索依赖顾问经验和关键词 | 人才库复用率提升空间大 |

## 4. MVP 成功标准

HR 上传 1 个项目需求和 50-200 份简历后，系统在 5 分钟内生成可解释候选人短名单。

短名单必须包含：

- 候选人总分和推荐级别。
- 技能、项目经验、行业经验、年限级别、语言能力、可用性等分项评分。
- 每项判断对应的简历证据或缺口说明。
- 风险点和建议人工确认问题。
- 可导出的短名单、面试准备表或结果 CSV。

## 5. 核心用户流程

1. HR 或项目负责人输入项目需求，例如技术栈、年限、行业经验、语言能力、到岗时间。
2. 系统将需求拆解为硬性条件、加分条件、权重、风险项和面试验证点。
3. HR 导入 PDF / Word 简历、ATS 导出的 CSV 或本地简历文件夹。
4. 系统在本地完成简历解析、字段抽取、脱敏、向量化和人才库入库。
5. 系统输出候选人排序、总分、分项分、推荐理由、风险点和证据来源。
6. HR 查看候选人详情，确认 AI 建议并生成针对性面试问题。
7. HR 导出短名单、面试准备表或结果 CSV，回写到既有 ATS 或人工使用。

## 6. MVP 页面

| 页面 | 核心能力 | 关键要求 |
| --- | --- | --- |
| 项目需求页 | 粘贴 JD / 项目需求，自动拆解条件和权重 | HR 必须能修改 AI 解析结果 |
| 简历导入页 | 上传 PDF / Word / CSV / 文件夹 | 明确展示本地解析、脱敏和入库状态 |
| 匹配结果页 | 候选人排序、总分、推荐级别、核心匹配点、风险点 | 列表必须可扫读，并支持查看证据 |
| 候选人详情页 | AI 摘要、分项评分、适合/不适合理由、简历证据 | 所有判断都要可追溯 |
| 面试问题页 | 技术验证题、项目复盘题、风险追问、评分表 | 问题必须基于项目需求和候选人真实经历 |

## 7. 第一版明确不做

- 不做完整 ATS 流程，例如职位发布、候选人门户、offer 审批、入职管理。
- 不做自动录用或自动淘汰决策，AI 只提供判断辅助。
- 不做视频面试、自动发拒信、自动日程协调等外围自动化。
- 不在第一版接入所有 ATS，先用 CSV / 简历包导入验证价值。
